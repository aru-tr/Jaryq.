# Jaryq — виртуалды оптика зертханасы

Оқулықтағы №4 зертханалық жұмысқа арналған қазақша интерактивті симулятор. Сыртқы JavaScript кітапханалары және құрастыру қадамы қажет емес.

## Іске қосу

```sh
cd /workspace/Jaryq.
python3 -m http.server 8000
```

Браузерде HTTP сервердің 8000 портын ашыңыз. Сондай-ақ `index.html` файлын статикалық хостингке орналастыруға болады. Қаріп жүктелмесе, жүйелік Arial қолданылады.

## Мүмкіндіктер

- Жұқа ауа қабатынан шағылған жарық интерференциясы: қалыңдық, бақылау бұрышы, ақ және монохроматты жарық.
- 0,50–0,80 мм саңылаудағы дифракция және 100 сызық/мм тор.
- Оқулықтың 5-кестесін өз бетімен толтыру және түсіндірме үлгісі.
- Малюс заңы: 0–360° бұрылу, 15° қадам, гальванометр, 6-кесте, I(cos²α) графигі, CSV экспорты.
- Тәжірибе көрінісін PNG ретінде сақтау; бақылау және қорытынды өрістері браузер сессиясында сақталады.

## Модельдің шектері

Нәтижелер идеалдандырылған теориялық модельден есептеледі; нақты өлшеулер емес. Интерференция үшін әлсіз қисық шыны беттер арасындағы ауа қабаты алынады. Дифракция — экранға дейінгі қашықтық 1 м болатын Фраунгофер моделі; торда 8 саңылау бар. Ақ жарық 400–700 нм аралығындағы 31 компонентпен жуықталады, экран жарықтығы көрнекілік үшін күшейтіледі. Поляризация үшін идеал анализатор және қараңғылық тогы нөлге тең сызықтық фотоэлемент алынады. I₀ өзгерсе, кесте әр өлшеудегі I₀-ді бөлек сақтайды; бір түзу алу үшін оны тұрақты ұстаңыз.

## Тексеру

`node --check app.js` — JavaScript синтаксисі. Браузерде төрт бөлімді, 90° кезінде нөлдік фототокты, өлшеу кестесін, торға ауысуды және мобильді орналасуды тексеріңіз.
