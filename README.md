# Jaryq — виртуалды оптика зертханасы

Қазақ тіліндегі интерференция, дифракция және поляризация симуляторы. Сыртқы JavaScript кітапханалары, пакет орнату және құрастыру қажет емес.

## Іске қосу

```sh
cd /workspace/Jaryq.
python3 -m http.server 8000 --bind 127.0.0.1
```

Сайтты статикалық хостингте де орналастыруға болады. Google Fonts қолжетімсіз болса, Arial қолданылады.

## Тәжірибелер

1. Құралды таңдап, атауына сәйкес орынға басыңыз немесе сүйреп апарыңыз. «Автоматты жинау» төрт құралды орналастырады. Жинақ толық болмаса, өлшеу басталмайды.
2. Әр параметрді жүгірткімен немесе санын қолмен теріп өзгертіңіз. Шектен тыс және бос мәндер есептеуге қабылданбайды.
3. «Мәнді кестеге енгізу» ағымдағы мәнді тіркейді. «25 мәнді автоматты өлшеу» сол тәжірибенің кестесін 25 нүктемен жаңартады. Қолмен енгізуде бірдей негізгі параметр бұрынғы жолды жаңартады; ең көбі 25 жол сақталады. Бекітілген басқа параметр өзгерсе, қолмен өлшеу жаңа серия бастайды.
4. Кестенің бірінші параметр бағанын түзетуге болады: қарқындылық және график қайта есептеледі. Әр жолда өлшеу кезіндегі параметрлер сақталады. Бір серияда бірдей екі параметр мәніне жол берілмейді.
5. Соңғы «Ортақ график» бөлімінде үш кесте және үш түсті сызық бар: көк — интерференция, қызғылт сары — дифракция, күлгін — поляризация. Кестелер CSV, график пен көрініс PNG форматында жүктеледі.

Өлшеулер мен жазбалар браузердің ағымдағы сессиясында сақталады. Бетті жаңартқанда кестелер қалады; құралдарды қайта жинау керек. Жаңа браузер сессиясына көшірілмейді. Мұғалімге жіберу барлық үш тәжірибенің нәтижелерін қамтиды; Supabase баптауы [SETUP.md](SETUP.md) ішінде сипатталған.

## 3D көрініс

Кеңістіктегі оптикалық үстел перспектива проекциясымен Canvas-та салынады. Камераны тышқанмен/саусақпен сүйреп немесе бағыт пернелерімен бұруға болады. Canvas таңдалғанда `+`/`−` масштабты өзгертеді, `0` камераны қалпына келтіреді. Құралдар жиналған сайын үстелде пайда болады. Поляризацияда анализатордың осі бұрышқа сәйкес бұрылады, датчик жарықтығы есептелген қарқындылықпен өзгереді. «2D жарық көрінісі» интерференция сақиналарын және дифракция жолақтарын ашады.

## Физикалық модель

- Интерференция: бір шағылудағы π фазалық ығысумен тең амплитудалы екі сәуле, `I/I₀ = sin²(2πd cos r / λ)`. Өлшеу аралығы `d = 0–2 мкм`; орталықтағы ауа қабаты өлшенеді. Суретте қисық шыны үшін `d(ρ) = d + ρ²/(2R)`, `R = 0,8 м`.
- Дифракция: Фраунгофер моделі, саңылау ені `0,50–0,80 мм`, экран қашықтығы `0,5–2 м`. `I/I₀ = sinc²(πa sin θ/λ)`, `sin θ = x/√(L²+x²)`. Торда 8 саңылау, период 10 мкм, әр саңылау ені 2 мкм; тор көбейткіші шектік нүктелерде аналитикалық есептеледі.
- Ақ жарық: 400–700 нм аралығындағы 31 толқын ұзындығының тең салмақты орташа қарқындылығы. Монохроматты жарықтың λ мәнін қолмен өзгертуге болады.
- Поляризация: Малюс заңы `I = I₀ cos²α`, идеал анализатор және сызықтық фотоэлемент; 90° және 270° кезінде ток нөлге тең.

Ортақ графиктің тік осі — `I/I₀`, көлденең осі — әр тәжірибенің өз өлшеу аралығының 0–100% үлесі: `d = 0–2 мкм`, `x = −4…4 мм` (торда `−75…75 мм`), `α = 0–360°`. Бірдей пайыз бірдей физикалық жағдайды білдірмейді. Сызықтар тек тіркелген нүктелерді қосады; 25 нүкте жіңішке максимумдардың бәрін қамтымауы мүмкін. Нақты максимумды табу үшін датчик орнын қолмен өзгертіңіз. Сурет жарықтылығы күшейтіледі, сандық өлшеу күшейтілмейді. Нәтижелер — теориялық модель, нақты аспаптың өлшеуі емес.

## Тексеру

```sh
node --test tests/physics.test.cjs
```

Формулалардың минимум/максимумдары, симметрия, қашықтыққа тәуелділік, ақ жарық, Малюс заңы және өлшеулерді сақтау тексеріледі.

HTTP сервер жұмыс істеп тұрғанда, Python Playwright және `/usr/bin/chromium` орнатылған ортада:

```sh
python3 tests/browser_smoke.py
```

Қолмен/автоматты құрастыру, сан енгізу, кестені түзету, 75 өлшеу, 2D/3D камера, CSV/PNG, сессияда сақтау және мобильді орналасу тексеріледі. Мұғалімге жіберу желілік сұрауы тестте ауыстырылады: қашықтағы дерекқорға дерек жазылмайды.
