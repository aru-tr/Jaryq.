# Jaryq — виртуалды оптика зертханасы

Қазақ тіліндегі интерференция, дифракция және поляризация симуляторы. Сыртқы JavaScript кітапханалары, пакет орнату және құрастыру қажет емес.

## Іске қосу

```sh
cd /workspace/Jaryq.
python3 -m http.server 8000 --bind 127.0.0.1
```

Сайтты статикалық хостингте де орналастыруға болады. Google Fonts қолжетімсіз болса, Arial қолданылады.

## Тәжірибелер

1. Құралдарды үстел үстінде еркін сүйреп жылжытыңыз. Нөмірленген орындар мен автоматты бекіту жоқ. Жарық көзі, оптикалық элементтер және датчик бір осьте, дұрыс ретпен тұруы керек. «Автоматты жинау» тураланған жинақты орнатады; «Бөлшектеу» құралдарды алып тастайды. Жоғарыдағы құрал батырмасымен оны үстелге қайта қосуға болады.
2. Әр параметрді жүгірткімен немесе санын қолмен теріп өзгертіңіз. Дифракцияда саңылау мен экранды жылжыту олардың физикалық қашықтығын да өзгертеді. Тураланбаған құралдармен өлшеу жүргізілмейді.
3. «Мәнді кестеге қосу» әр басқанда жаңа жол қосады. Бірдей мән де, басқа параметрлермен өлшенген мән де сақталады; бұрынғы жолдар өшірілмейді. Автоматты өлшеуде нүкте санын енгізіңіз: бастапқысы 101, ең азы 2. Әр жаңа серия кестенің соңына қосылады. Өлшеулер санына қолданба деңгейінде шек қойылмаған; қолжетімді көлем құрылғының жады мен сақтау орнына байланысты.
4. Кестенің бірінші параметр бағанын түзетсеңіз, қарқындылық және график қайта есептеледі. Үлкен кестелер 100 жолдан беттерге бөлінеді, график пен CSV барлық жолды қамтиды. Мәндердің бекітілген параметрлері өзгерсе, график оларды бөлек сериялар ретінде сол тәжірибенің түсімен сызады.
5. «Ортақ график» бөлімінде үш кесте және барлық тіркелген нүкте көрсетіледі: көк — интерференция, қызғылт сары — дифракция, күлгін — поляризация. Кестелер CSV, график пен көрініс PNG форматында жүктеледі.

Өлшеулер браузер сессиясына байланыстырылып sessionStorage және IndexedDB-де сақталады. Бетті жаңартқанда үлкен кестелер де қалпына келеді. Сақтау орны толса, хабарлама көрсетіледі және CSV жүктеуге болады. Қолданба құрылғы жадынан тыс шексіз сақтау көлеміне кепілдік бермейді.

Мұғалімге жібергенде барлық мән қолданыстағы Supabase шектеріне сәйкес шағын бөліктермен жіберіледі. Қайта жіберу сол идентификаторлармен қалған бөліктерді жалғастырады; мұғалім панелі бөліктерді бір жұмысқа біріктіреді. Дерекқор схемасын өзгерту қажет емес. Жұмыстың барлық бөлігі әлі жүктелмесе, панель оның санын көрсетеді, қалғандарын «Тағы 100 жұмысты жүктеу» арқылы алуға болады. Supabase баптауы [SETUP.md](SETUP.md) ішінде сипатталған.

## Жарық көрінісі және 3D

Бастапқыда ақ жарықтың түрлі түсті интерференция сақиналары көрсетіледі. Дифракцияда ақ орталық максимум және екі жағындағы спектрлер көрінеді. «Монохроматты жарық» таңдалса, көрініс таңдалған толқын ұзындығының түсімен салынады.

«3D құралдар көрінісі» перспективасы бар кеңістіктегі үстелді ашады. Құралдың өзін сүйресеңіз, ол үстел жазықтығында еркін қозғалады; бос жерді сүйресеңіз, камера бұрылады. «Үстінен», «Алдынан», «Қиғаш» батырмалары камераны бірден қажетті жаққа қояды. Камераны бағыт пернелерімен де бұруға болады; `+`/`−` масштабты, `0` бастапқы көріністі қалпына келтіреді. «Үстінен» көрінісі шынымен үстелдің жоғарғы жағын көрсетеді. 3D режимінде жарықтың түрлі түсті көрінісі бөлек жақындатылған терезеде де көрсетіледі.

## Физикалық модель

- Интерференция: бір шағылудағы π фазалық ығысумен тең амплитудалы екі сәуле, `I/I₀ = sin²(2πd cos r / λ)`. Өлшеу аралығы `d = 0–2 мкм`; орталықтағы ауа қабаты өлшенеді. Суретте қисық шыны үшін `d(ρ) = d + ρ²/(2R)`, `R = 0,8 м`.
- Дифракция: Фраунгофер моделі, саңылау ені `0,50–0,80 мм`, экран қашықтығы `0,5–2 м`. `I/I₀ = sinc²(πa sin θ/λ)`, `sin θ = x/√(L²+x²)`. Торда 8 саңылау, период 10 мкм, әр саңылау ені 2 мкм; тор көбейткіші шектік нүктелерде аналитикалық есептеледі.
- Ақ жарық: 400–700 нм аралығындағы 31 толқын ұзындығының тең салмақты орташа қарқындылығы. Монохроматты жарықтың λ мәнін қолмен өзгертуге болады.
- Поляризация: Малюс заңы `I = I₀ cos²α`, идеал анализатор және сызықтық фотоэлемент; 90° және 270° кезінде ток нөлге тең.

Ортақ графиктің тік осі — `I/I₀`, көлденең осі — әр тәжірибенің өз өлшеу аралығының 0–100% үлесі: `d = 0–2 мкм`, `x = −4…4 мм` (торда `−75…75 мм`), `α = 0–360°`. Бірдей пайыз бірдей физикалық жағдайды білдірмейді. Сызықтар тек тіркелген нүктелерді қосады; Нүктелер сирек болса, жіңішке максимумдар байқалмай қалуы мүмкін: автоматты өлшеудегі нүкте санын көбейтіңіз. Нақты максимумды табу үшін датчик орнын қолмен өзгертіңіз. Сурет жарықтылығы күшейтіледі, сандық өлшеу күшейтілмейді. Нәтижелер — теориялық модель, нақты аспаптың өлшеуі емес.

## Тексеру

```sh
node --test tests/physics.test.cjs
```

Формулалардың минимум/максимумдары, симметрия, қашықтыққа тәуелділік, ақ жарық, Малюс заңы және өлшеулерді сақтау тексеріледі.

HTTP сервер жұмыс істеп тұрғанда, Python Playwright және `/usr/bin/chromium` орнатылған ортада:

```sh
python3 tests/browser_smoke.py
```

Қолмен/автоматты құрастыру, сан енгізу, кестені түзету, 900-ден астам өлшеу, 2D/3D камера, CSV/PNG, IndexedDB-де сақтау, бөліктермен жіберуді жалғастыру және мобильді орналасу тексеріледі. Мұғалімге жіберу желілік сұрауы тестте ауыстырылады: қашықтағы дерекқорға дерек жазылмайды.
